# Daily Randomizer

Десктоп-приложение на Kotlin + Spring Boot для случайного выбора человека, который будет проводить дейли на работе.

**Текущая версия: 2.0.1** (фикс: накопление листенеров при смене темы).

## Стек

- Kotlin 2.3.21, JVM 21 (Temurin)
- Spring Boot 4.1.1 (контекст приложения, DI)
- Swing (UI, без нативных зависимостей)
- Jackson (хранение списка участников в JSON)
- Gradle 8.14 (wrapper, совпадает с локальной установкой в IDEA)

## Запуск

**Fat jar** (рекомендуется — не зависит от Gradle-демона):

```bash
./gradlew bootJar
java -jar build/libs/daily-randomizer-2.0.1.jar
```

**Для отладки** — из IDEA или:

```bash
./gradlew run
```

Сборка без тестов: `./gradlew build -x test`. Тесты: `./gradlew test`.

> Примечание: для сборки нужен доступ к Maven Central (сеть). В изолированных сессиях без сети сборка падает с TLS-ошибкой.

## Функциональность

- **Главное окно**: окошко с именем, кнопка «Крутить», кнопка «⚙ Настройки» в правом верхнем углу.
- **Прокрутка**: плавная анимация «как в казино» (~60 FPS, сверху вниз, зацикленная лента, торможение), затем выводится победитель с фейерверком и переливающимся именем.
- **Пул участников**: в настройках у каждого имени чекбокс (участвует в пуле сегодня или нет), кнопки «Добавить всех» / «Убрать всех». Кнопка «Крутить» крутит только отмеченных.
- **После победы**: кнопка меняется на «Перекрутить» (если человек не может вести), кнопка «Провести» убирает победителя из пула.
- **Настройки**: модальный диалог с вкладками «Участники» и «Тема». Валидация: пустые имена и дубликаты (без учёта регистра) отклоняются.
- **Темы**: плитки с превью — «Казино» (зелёное сукно, золото, круглая фишка, виньетка) и «Райффайзен» (жёлтый на тёмно-сером, диагональные линии, плоская кнопка, логотип Giebelkreuz, фирменный салют). Тема переключается на лету, без перезапуска.
- **Хранение**: список участников (с флагами пула) сохраняется в `~/.daily-randomizer/names.json` и переживает перезапуск.

## Структура кода

```
src/main/kotlin/ru/raiffeisen/daily_randomizer/
├── DailyRandomizerApplication.kt   # Spring Boot точка входа, запуск UI на EDT
├── service/
│   ├── Participant.kt              # модель участника (name + inPool)
│   ├── ParticipantStorage.kt       # JSON-хранилище (~/.daily-randomizer/names.json)
│   └── ParticipantService.kt       # добавление/удаление/управление пулом/случайный выбор
└── ui/
    ├── MainFrame.kt                # главное окно
    ├── SettingsDialog.kt           # диалог настроек (вкладки, чекбоксы пула, плитки тем)
    ├── AppTheme.kt                 # модель темы (палитра, узор фона, стиль кнопки)
    ├── CasinoTheme.kt              # палитра и стили, делегирует текущей теме
    ├── RaifLogoComponent.kt        # логотип Giebelkreuz (рисуется программно)
    ├── FeltBackgroundPanel.kt      # фон: градиент + узор по теме
    ├── FireworksOverlay.kt         # полноэкранный салют поверх окна
    ├── SlotReel.kt                 # барабан слот-машины, победитель
    ├── SpinSequenceGenerator.kt    # чистая логика последовательности прокрутки
    └── SpinAnimator.kt             # плавная анимация ~60 FPS
```

Тесты: `ParticipantServiceTest` (валидация, дубликаты, пул), `SpinSequenceGeneratorTest` (длина, границы).

## Известные ограничения

- Запуск из сессии без доступа к WindowServer (SSH, CI) даёт `HeadlessException` — приложение требует GUI-окружения.
- Предупреждение `WARNING Ignored custom Gradle user home location...` не критично и на работу не влияет.
